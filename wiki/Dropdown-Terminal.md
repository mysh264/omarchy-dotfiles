# Dropdown terminal (TildaZ, Kitty fallback)

> **Current setup:** the dropdown keys run **[TildaZ](https://github.com/ensky0/tildaz)** (`tildaz --toggle`). The Kitty-on-a-special-workspace setup below is still in the repo as a fallback. See [Switching between TildaZ and Kitty](#switching-between-tildaz-and-kitty).

## TildaZ (in use)

| Piece | File | Role |
|-------|------|------|
| Toggle binds | `hypr/bindings.lua` | `XF86Favorites`, KP Delete (`code:91`), mouse forward (`mouse:276`) → `{ launch = "tildaz --toggle" }` |
| Autostart | `~/.config/hypr/tildaz.lua` | Written by `tildaz --desktop add`. Starts TildaZ at login and sets `autogenerated = false` so Hyprland's warning bar does not cover the top of the screen |
| Loader | `hypr/hyprland.lua` | `pcall(require, "tildaz")` at the end — loads `tildaz.lua` if it exists, does nothing if not |

`tildaz.lua` is **not** in this repo: TildaZ generates it with a path for the local user. On a new machine:

```bash
# install TildaZ (see its README), then:
tildaz --desktop add      # writes ~/.config/hypr/tildaz.lua
hyprctl reload && hyprctl configerrors
```

Remove it with `tildaz --desktop remove`. Without TildaZ installed, the dropdown keys do nothing — switch back to Kitty below.

## Switching between TildaZ and Kitty

In `hypr/bindings.lua`, the three binds:

```lua
-- TildaZ (current)
o.bind("XF86Favorites", "Dropdown terminal", { launch = "tildaz --toggle" })
o.bind("code:91", "Dropdown terminal", { launch = "tildaz --toggle" }) -- KP Delete
o.bind("mouse:276", "Dropdown terminal", { launch = "tildaz --toggle" })

-- Kitty on special:dropdown
o.bind("XF86Favorites", "Dropdown terminal", toggle_dropdown())
o.bind("code:91", "Dropdown terminal", toggle_dropdown()) -- KP Delete
o.bind("mouse:276", "Dropdown terminal", toggle_dropdown())
```

For Kitty, also put back the Kitty line inside `toggle_dropdown()` (it currently runs `tildaz --toggle` when no Kitty dropdown exists):

```lua
hl.exec_cmd(o.launch("kitty --class dropdown.terminal"))
```

`autostart.lua` still starts a hidden Kitty dropdown at login (`o.launch_on_start("kitty --class dropdown.terminal")`). With TildaZ you can remove that line.

# Kitty + special workspace (fallback)

Quake-style terminal on Wayland using a Hyprland **special workspace** — not Guake/Yakuake (X11-oriented).

## How the pieces connect

| Piece | File | Role |
|-------|------|------|
| Window rule | `hyprland.lua` | Class `dropdown.terminal` → `special:dropdown`, float, 40% height |
| Autostart | `autostart.lua` | `kitty --class dropdown.terminal` at login |
| Toggle | `bindings.lua` | Favorites / KP Delete / mouse forward |

**Class must stay `dropdown.terminal`** so normal Kitty (`Super+Shift+Return`) is unaffected.

## Window rule (edit size / opacity)

```lua
o.window({ class = "^dropdown\\.terminal$" }, {
  workspace = "special:dropdown silent",
  float = true,
  move = { 0, 0 },
  size = { "monitor_w", "monitor_h * 0.4" },  -- change 0.4 for taller/shorter
  opacity = "0.95 0.95",
})
```

## Toggle binds (shipped)

| Shortcut | Action |
|----------|--------|
| `XF86Favorites` | Toggle dropdown |
| KP Delete (`code:91`) | Toggle dropdown |
| Mouse forward (`mouse:276`) | Toggle dropdown |
| Mouse back (`mouse:275`) | Previous workspace (not dropdown) |

`toggle_dropdown()` relaunches Kitty if you closed the window, then `toggle_special("dropdown")`.

**Do not** pass `{ mouse = true }` on click toggles — that flag is for drag/resize and the click never runs.

## Verify

```bash
hyprctl reload && hyprctl configerrors
uwsm-app -- kitty --class dropdown.terminal   # if not autostarted yet
# press Favorites / mouse forward twice

hyprctl clients -j | python3 -c 'import json,sys
for c in json.load(sys.stdin):
  if c.get("class")=="dropdown.terminal":
    print("ws", c.get("workspace"), "float", c.get("floating"), "size", c.get("size"))'
```

## Side buttons not working?

```bash
wev   # hold button over a window; want mouse:275 / mouse:276
hyprctl binds -j | python3 -c 'import json,sys
for b in json.load(sys.stdin):
  if str(b.get("key","")).startswith("mouse:27"):
    print(b.get("key"), b.get("description"))'
```
